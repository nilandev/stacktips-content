You can follow below steps to create and delete branches from GitHub.com

1.  Create a new account in GitHub.com if you don’t have one. Once you are ready with new account, just login into GitHub.com.
2.  In your repository’s dashboard you can click on the add button in the right top besides your username. Now start typing a new branch name, description and select repository type public/private. Private repositories aren’t free. It is always a good practice a to README file in your repository.
