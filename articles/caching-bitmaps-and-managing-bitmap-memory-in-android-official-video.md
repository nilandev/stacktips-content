Applications are enriched with graphics and images. But when your app have to load a number of bitmap, memory allocation will get complicated. Here is the official video lessons on caching bitmaps and managing bitmap memory in android. Here you will find below two points explained in detailed with a sample demo.

**1\. [Caching Bitmaps](http://developer.android.com/training/displaying-bitmaps/cache-bitmap.html),** in this section you can learn how to use a memory and disk bitmap cache to improve the responsiveness and fluidity of your User Interface when loading multiple bitmaps.

**2\. [Managing Bitmap Memory](http://developer.android.com/training/displaying-bitmaps/manage-memory.html),** this section you will see more on how to facilitate garbage collection and reuse bitmaps more effectively.

In this video tutorial you will also get an overview of, how to speed up bitmap loading and reduce garbage collection by reusing existing bitmaps.
