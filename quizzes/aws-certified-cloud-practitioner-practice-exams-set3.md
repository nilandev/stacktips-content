# CLF-C01 AWS Certified Cloud Practitioner Practice Exam- Set3

**Difficulty:** beginner  
**Duration:** 15 minutes  
**Questions:** 10

## Description

The test contains 30 questions and has a time imit of 30 minutes

---

## Questions

### Question 1
**Which service would be used to send alerts based on Amazon CloudWatch alarms?**

- [ ] AWS CloudTrail
- [ ] AWS Trusted Advisor
- [x] Amazon Simple Notification Service (Amazon SNS)
- [ ] Amazon Route 53

**Explanation:** Amazon SNS and Amazon CloudWatch are integrated so users can collect, view, and analyze metrics for every active SNS. Once users have configured CloudWatch for Amazon SNS, they can gain better insight into the performance of their Amazon SNS topics, push notifications, and SMS deliveries.

---

### Question 2
**Where can a user find information about prohibited actions on the AWS infrastructure?**

- [ ] AWS Trusted Advisor
- [ ] AWS Billing Console
- [ ] AWS Identity and Access Management (IAM)
- [x] AWS Acceptable Use Policy

**Explanation:** The AWS Acceptable Use Policy provides information regarding prohibited actions on the AWS infrastructure.

---

### Question 3
**What AWS storage class should be used for long-term, archival storage?**

- [ ] Long-Term
- [ ] Infrequent Access
- [x] Glacier
- [ ] Standard

**Explanation:** Glacier should be used for (and is specifically designed for) long-term , archival storage.

---

### Question 4
**Kim is managing a web application running on the AWS cloud. The application is currently utilizing eight EC2 servers for its compute platform. Earlier today, two of those web servers crashed; however, none of her customer were effected. What has Kim done correctly in this scenario?**

- [ ] Properly built a scalable system
- [ ] None of the above
- [x] Properly build a fault tolerant system.
- [ ] Properly built an elastic system.

**Explanation:** A fault tolerant system is one that can sustain a certain amount of failure while still remaining operational.

---

### Question 5
**S3 storage classes are rated by what two metric categories? Choose the 2 Correct answers**

- [ ] Objectivity
- [x] Availability
- [x] Durability
- [ ] Fault tolerance

**Explanation:** Each S3 storage class is rated on its availability and durability.

---

### Question 6
**If an object is stored in the Standard S3 storage class and you want to move it to Glacier, what must you do in order to properly migrate it?**

- [ ] Change the storage class directly on the object.
- [x] Create a lifecycle policy that will migrate it after a minimum of 30 days.
- [ ] None of the above
- [ ] Delete the object and reupload it, selecting Glacier as the storage class.

**Explanation:** Any object uploaded to S3 must first be placed into either the Standard, Reduced Redundancy,
or Infrequent Access storage class. Once in S3 the only way to move the object to glacier is through a lifecycle policy.

---

### Question 7
**What is the most common type of storage used for EC2 instances?**

- [x] Elastic Block Store (EBS)
- [ ] Elastic File System (EFS)
- [ ] EC2 Hard Drives
- [ ] Magnetic Drive (MD)

**Explanation:** EC2 instance have several different hard drive options. However, Elastic Block Store (EBS), which is a type of Network Attached Storage, is the most popular and widely used.

---

### Question 8
**What are the primary benefits of using Lambda?**

- [x] Run code without provisioning server
- [ ] Wide variety of operating systems to select from.
- [x] Pay for only the compute time you consume.
- [ ] Actively select and manage instance type and capacity.

**Explanation:** Lambda, being AWS's serverless compute platform, means there are no servers, instance types, or capacity to select. That is all managed for you. With Lambda, you only for the when your code is actually being executed.

---

### Question 9
**If you want in-depth details on how to create, manage, and attach IAM access policies to IAM users, in what AWS resource should you look?**

- [x] AWS Service Documentation
- [ ] None of the above
- [ ] AWS How-To-Help Section
- [ ] AWS Whitepapers

**Explanation:** AWS Service documentation is a collection of documents specific to each AWS service. They contain detailed how-to's, as well as technical walkthroughs and specifications.

---

### Question 10
**If you want to learn about AWS architectural or security best practices, where will you find that type of information?**

- [ ] AWS Console Info Section
- [ ] AWS Service Documentation
- [x] AWS White Papers
- [ ] AWS Yellow Pages

**Explanation:** White papers are a collection of technical documents that outlines many AWS relevant topics.
