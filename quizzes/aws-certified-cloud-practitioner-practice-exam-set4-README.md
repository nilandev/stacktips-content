## Questions

### Question 1
**Which component of the AWS global infrastructure does Amazon CloudFront use to ensure low-latency delivery?**

- [ ] Availability Zones
- [x] Edge locations
- [ ] AWS Regions
- [ ] Virtual Private Cloud

**Explanation:** To deliver content to users with lower latency, Amazon CloudFront uses a global network of points of
presence (edge locations and regional edge caches) worldwide.

---

### Question 2
**How would a system administrator add an additional layer of login security to a user's AWS Management Console?**

- [ ] Use Amazon Cloud Directory
- [ ] Audit AWS Identity and Access Management (IAM) roles
- [ ] Enable AWS CloudTrail
- [x] Enable multi-factor authentication

**Explanation:** Multi-factor authentication (MFA) is a simple best practice that adds an extra layer of protection on top of a username and password. With MFA enabled, when a user signs in to an AWS Management Console, they will be prompted for their username and password (the first factor?what they know), as well as for an authentication code from their MFA device (the second factor?what they have). Taken together, these multiple factors provide increased security for AWS account settings and resources.

---

### Question 3
**Which service can identify the user that made the API call when an Amazon EC2 instance is terminated?**

- [ ] AWS Trusted Advisor
- [x] AWS CloudTrail
- [ ] AWS X-Ray
- [ ] AWS Identity and Access Management (AWS IAM)

**Explanation:** AWS CloudTrail helps users enable governance, compliance, and operational and risk auditing of their AWS accounts. Actions taken by a user, role, or an AWS service are recorded as events in CloudTrail. Events include actions taken in the AWS Management Console, AWS Command Line Interface (CLI), and AWS SDKs and APIs.

### Question 5
**Which S3 storage class has lowest object availability rating?**

- [x] Infrequent Access
- [ ] Reduced Redundancy
- [ ] Standard
- [ ] All of them have the same availability rating

**Explanation:** Infrequent access has the lowest availability rating (99.90%). Standard and Reduced Redundancy have an availability rating of 99.99%

### Question 6
**John is working with a large data set, and he needs to import it into a relational database service. What AWS service will meet his needs?**

- [x] RDS
- [ ] NoSQL
- [ ] DynamoDB
- [ ] Redshift

**Explanation:** RDS is AWS's relational database service.

---

### Question 7
**Derek is running a web application and is noticing that he is paying for way more server capacity then is required. What AWS feature should Derek set up and configure to ensure that his application is automatically adding/removing server capacity to keep in line with the required demand?**

- [ ] Elastic Load Balancing
- [ ] Elastic Server Scaling
- [x] Auto Scaling
- [ ] Auto Sizing

**Explanation:** Auto scaling is the feature that automated the process of adding/removing server capacity from a system (based on usage demand). Auto scaling creates a very cost effective system by never having too much or too little server capacity.

---

### Question 8
**What are the benefits of AWS Organizations? (Select all that apply)**

- [x] Automate AWS account creation and management.
- [x] Centrally manage access polices across multiple AWS accounts.
- [ ] Analyze cost across all multiple AWS accounts.
- [ ] None of the above

**Explanation:** AWS Organizations has four main benefits: 1) Centrally manage access polices across multiple AWS accounts. 2) Automate AWS account creation and management. 3) Control access to AWS services 4) Enable consolidated billing across multiple AWS accounts Analyzing cost is done through the Cost Explorer (or TCO calculator), which is not part of AWS Organizations.

### Question 9
**Under what circumstances would you choose to use the AWS service CloudTrail?**

- [x] When you want to log what actions various IAM users are taking in your AWS account.
- [ ] When you want a serverless compute platform.
- [ ] When you want to collect and view resource metrics.
- [ ] When you want to send SMS notificaitions based on events that occur in your account

**Explanation:** CloudTrail is AWS's logging service used to log actions taken by users in your AWS account.

### Question 10
**Which AWS service uses a combination of publishers and subscribers?**

- [x] SNS
- [ ] EC2
- [ ] RDS
- [ ] Lambda

**Explanation:** In SNS, there are two types of clients: publishers and subscribers. Publishers send the message, and subscribers receive the message.
